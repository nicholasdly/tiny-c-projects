# tiny-c-projects

My solutions to the 15 projects in [*Tiny C Projects*](https://www.manning.com/books/tiny-c-projects).

## Usage

Use your favorite compiler to compile a solution:

```bash
clang -Wall -Wextra -g -o bin/greetings greetings/greet05.c
```

Run the compiled binary:

```bash
./bin/greetings
```
